# About This Site

Welcome! This digital garden is built with Quartz v4, a fast static site generator designed for publishing your digital garden or notes.

## What is a Digital Garden?

A digital garden is a different approach to blogging and content creation:

- **Growing Over Time**: Content evolves rather than being published once and forgotten
- **Non-Linear**: Pages connect through links rather than chronological order
- **Work in Progress**: It's okay for content to be incomplete or rough
- **Exploration**: Follow curiosity rather than strict categories

## Technology Stack

This site is powered by:

- **[Quartz v4](https://quartz.jzhao.xyz)** - Static site generator
- **Markdown** - Simple, plain-text formatting
- **GitHub Pages** - Free hosting
- **GitHub Actions** - Automated deployment

## How It Works

1. Write notes in Markdown in the `content/` folder
2. Link between notes using `[[wikilinks]]`
3. Push to GitHub
4. GitHub Actions automatically builds and deploys

## Navigation

Use the search feature, browse by tags, or follow links between notes to explore the content. The graph view shows connections between different notes.
