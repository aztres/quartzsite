# Session Retrospectives Index

This directory contains session retrospectives documenting learnings, patterns, and decisions made during Quartzsite development.

## How to Use

1. **Before starting work:** Review recent retrospectives to refresh context
2. **During work:** Note discoveries and patterns
3. **After work:** Create a new retrospective using the template

## Creating a New Retrospective

```bash
cp .claude/SESSION-RETROSPECTIVE-TEMPLATE.md .claude/retrospectives/$(date +%Y-%m-%d)-topic-name.md
```
